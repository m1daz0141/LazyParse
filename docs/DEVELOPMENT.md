# 開発状況

## 確認済み

- 対応版Classic x64での取得、画面ダメージとの照合、停止・再開、移動・再起動時の新run。
- 人物・敵・所有者・ペット帰属、回復候補の集計除外、JA/Critの限定した照合。
- GUIからの開始・区切り・停止・取得終了、保存・履歴、DPS方式・Time表示の切替。
- ソロの森林探索で、クリア時計固定、帰還結果追記、同名再受注時の新計測。

## 次の確認

1. GUI経由のクエスト破棄→再受注。
2. 失敗・リトライ、他種のクエストの通知と自動区切り。
3. 未登録Attack IDと状態異常の帰属。

未登録`0x07BADBDB`と`0x6B121351`はスラッグスキャッターのフォメル/ザンディ後に観測された。エンハンスコンボ後のクイックスラッシュのような動作という候補はあるが未確認。入力を有無で分けて照合してから辞書へ反映する。

バーンのIDは辞書と一致していても、発生元headerが0の場合は付与者不明として保持する。名前対応だけで本人へ加算しない。付与時点の通知から帰属できるか調べる。

終了付近の受信登録の途切れの原因調査は優先度を下げる。ゲーム終了と停止操作の順序による可能性は未確定。途切れを保存し、影響区間の判定を保留する処理は維持する。

実機ログ・画像・個人設定・詳細な引き継ぎ文書は公開リポジトリに含めない。新しい記録も人物名やIDを含むため、Git管理対象には加えない。
