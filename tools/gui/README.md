# LazyParse GUI

起動はリポジトリ直下の`./Start-LazyParse.ps1`。`Start-OverParse.ps1`は互換入口です。Python 3.13/Tk、PowerShell 7を使います。

## メニュー

| メニュー | 操作 |
|---|---|
| 計測 | 開始、停止、保存して次へ、リセット、取得終了、クエスト自動計測、Time小数表示 |
| DPS | クエスト中／ダメージ計測を排他選択 |
| 解析 | プレイヤーのみ、自分のみ、人物名の匿名表示、取得品質、攻撃名CSVの編集・再読込 |
| 表示 | 最前面、透明度、列、フォント、バー・自分の強調 |
| ログ | OPCAP/JSONを開く、最新状態、履歴、一覧コピー、JSON保存 |

クエスト中は最初のプレイヤー与ダメージから終了までの連続時間で、無攻撃・移動も含みます。ダメージ計測は従来方式で、既定10秒以上の無ダメージで分けた正値区間の最初～最後を合算します。単発区間は0秒、分母0のDPSは「—」。方式は自動クエスト区切りのON/OFFと独立しています。

Timeの小数表示は既定ONで2桁。OFFでは整数秒を切り捨て表示し、DPSの計算精度は変更しません。主画面・詳細・コピー・手動JSONに同じDPS方式を使います。手動JSONは両方の時間定義を保持します。古いJSONで連続時間を復元できない場合は元OPCAPを開いてください。

JA/Critセルへカーソルを置くと成立・対象・対象外・未判定の件数を表示します。ペットのJAは対象外です。行のダブルクリックで攻撃別、発生元、識別・品質を確認できます。

## 取得との関係

既定では`tools/native_capture/bin/autostart-build.json`へ追従します。GUIでDLL配置やゲーム起動は行いません。「取得を終了」はワーカーを停止しますが、ゲームを終了したり追加DLLを撤去したりはしません。GUIを閉じるだけでは取得を停止しません。[取得の手順](../native_capture/README.md)を参照してください。

自動計測は試験中で既定ON。対応する通知を検出したクエストごとに区分し、クリア候補で時計固定、次のworldで新しい区間へ切り替えます。結果通知は前の計測へ追記します。終了後・未確定の値は別枠へ保持します。登録先の途切れは、その時刻以降の判定を保留し、以前の完了周回を保持します。未知版・時刻不明の欠落等では推定を保留します。

設定は`state/preferences.json`、自動保存は`state/logs/`。いずれもGit管理外です。ログの匿名表示は画面・コピーだけに適用し、元の記録やJSONに含まれる人物情報は残ります。保存ログを開いている間は取得操作を無効にします。

```powershell
py -3 -m unittest tools.gui.test_gui -v
```

実機fixtureやnativeビルドが必要なケースは、それらがない場合skipします。
