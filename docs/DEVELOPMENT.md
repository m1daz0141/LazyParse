# 開発状況

## 現在の構成

Windows x64の単体exe、GUIからの追加DLL配置、exe隣のconfig/logs、編集用quests.csv/skills.csvを実装しています。ゲーム原本の置き換えや、外部へのテレメトリー送信は行いません。

ソロの保存記録で、人物・敵・ペット所有者の識別、回復と発生元0バーンの集計除外、限定したJA/Crit照合を確認しています。森林探索のクリア・周回・破棄、最終決戦の失敗後帰還・リトライなどで取得と自動計測を検査しました。独極2種・決闘・ディバイド最終ステージ・残滓の各通知形式は、保存した原本を再解析して判定を検査しています。

クエストの通知形式は種類・サイズ・順序と時刻で照合し、クリアで停止した計測を帰還時に再停止しません。ディバイドはステージごとの計測を維持します。未確認形式は追加照合が必要です。

2026-10-24の更新では、極限訓練「森林と龍」の短い最終通知列と、黒ノ領域探索・浮上施設探索の36バイト結果通知へ対応しました。保存した原本で途中ステージの継続、クリア時の時計固定、帰還・次周回との分離を検査しています。

GUIの「表示」から背景・アクセントのRGBと背景画像を変更でき、デフォルトへ戻せます。画像はローカルのconfig内へコピーし、実行フォルダーの移動後も保持します。画像処理用Pillowはexeに同梱します。通常状態は「待機中」「計測中」で表示し、詳しい終了理由は診断データへ保持します。ソース版の起動はStart-LazyParse.ps1を使用し、旧名の互換スクリプトは削除しました。

## 次の確認

- タイトル画面から再ログインした後の再接続修正版と、配布用コード整理後の実機確認。
- 複数プレイヤーの同時戦闘、未確認クエストや新しい終了通知。
- 未登録Attack IDは編集用skills.csvで追加できます。発生元0から状態異常の付与者を復元する機能は対象外です。

取得DLLは対応するゲーム版のハッシュを検査します。更新されたゲーム版は、静的照合・模擬試験・実機確認を分けて評価します。現在のprofile内にある検証フラグは、その作成時点の検証範囲を示します。

テストと調査ツールは開発用として保持し、本番exeには模擬DLL・テストモジュール・開発用スクリーンショット機能・旧コードパッチ方式を含めません。個人設定・実機ログ・抽出したゲームデータ・詳細な引き継ぎ文書は公開しません。非配布fixtureが必要な試験はskipします。
